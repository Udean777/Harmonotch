Cara Pasang di Mac Anda

Sekitar satu menit.

1. Unduh DMG

Klik Unduh DMG untuk mengambil rilis terbaru dari GitHub Releases.

2. Seret ke Applications

Buka file DMG, lalu seret ikon Harmonotch ke folder Applications.

3. Jika macOS Menolak Membuka Aplikasi

Rilis ini ditandatangani secara ad-hoc, jadi macOS bisa menampilkan 'Harmonotch cannot be opened'. Buka System Settings → Privacy & Security, lalu klik 'Open Anyway'. Di macOS 14 atau lebih lama, klik kanan aplikasi dan pilih 'Open'. Jika masih gagal, jalankan perintah di bawah di Terminal.

$ xattr -cr /Applications/Harmonotch.app

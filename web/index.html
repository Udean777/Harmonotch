Cara Pasang di Mac Anda

Hanya butuh waktu kurang dari satu menit untuk mulai menikmati Harmonotch.

1. Unduh File Installer

Klik tombol 'Unduh Installer (DMG)' untuk mengunduh paket resmi terbaru dari GitHub Releases.

2. Drag ke Applications

Buka file DMG yang diunduh, lalu seret ikon Harmonotch ke folder Applications Mac Anda.

3. Catatan Gatekeeper (Opsional)

Karena Harmonotch dirilis secara independen (ad-hoc signed), jika macOS memunculkan notifikasi keamanan 'Harmonotch cannot be opened', cukup jalankan perintah berikut di Terminal:

$ xattr -cr /Applications/Harmonotch.app
